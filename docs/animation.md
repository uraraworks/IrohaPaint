# パラパラ（アニメ）

1 作品に複数のコマを持たせ、前のコマを薄く見ながら次のコマを描き、繰り返し再生する。
セル画／パラパラ漫画の作り方。2026-09-11 に画面の形を決めた。保存の土台は `docs/page-versions.md`。

## 決めたこと

- 画面での呼び名は **「パラパラ」**（大人向けの説明・告知では「アニメ」でよい）
- **1 コマ = 1 枚の絵**。コマに複数のかさねは持たせない
- ツールバーの「パラパラ」で始める。かさねが 2 枚以上ある作品では、始める前に一度だけ
  「かさねを 1 まいに まとめるね」と確かめる（1 枚ならそのまま始まる）
  - まとめるのは **見えているかさねだけ**（不透明度込み。`Surface` の `composite()` と同じ結果）。
    隠していたかさねは残らないが、**まとめる直前に控えを撮る**ので「前に戻す」で取り戻せる
- パラパラ中は「かさね」ボタンを休ませる（1 コマ 1 枚の約束を画面でも守る）
- **コマの帯は縦**。かさねの帯と同じ左の場所・同じ触り方（押す＝そのコマへ／長押し＝持ち上げて
  並べ替え／けす前に確かめる）。横のフィルム案は、下のツールバーと場所を取り合い、スマホで紙が
  さらに狭くなるので採らなかった
  - 並びは上から 1 コマ目（かさねの帯は「上ほど上の層」で逆順だが、コマは時間順）
- 「＋」で **今のコマのすぐ後ろに白紙のコマ** を足し、そのコマへ移る
- 「うすく」スイッチ 1 つで、**直前の 1 コマ** を紙に薄く敷く。既定はオン。濃さは固定
  - 敷くのはレイヤー画像（透過）。合成画像（`PageData.image`）は紙色で塗られているので使わない
- 「見る」で 1 コマ目から最後まで **1 秒に 6 コマ** で繰り返し再生。紙を押すと止まる
- コマは **24 まで**。24 コマ目で「＋」を薄くし、押すと「ここまでだよ」と伝える
- 「戻る」は今のコマの中だけで効く。コマを切り替えたら戻る履歴は捨てる（作品を開き直すのと同じ）
- 作品一覧のサムネイルは **1 コマ目**（表紙）
- コマを消すと `pages` から外す。取り戻したいときは「前に戻す」の控えが受け皿
  （かさねを消したときと同じ扱い）
- GIF・動画の書き出しは今回やらない

## データ

- `WorkRecord.animation: boolean` … パラパラの作品か。古いデータ・今までの作品は `false`
- `WorkRecord.activePageId?: string` … 最後に開いていたコマ。無い・見つからなければ 1 コマ目
- 控え（`WorkSnapshot`）は今までどおり全コマを持つ。「前に戻す」は **全コマを** 控えの姿に戻す
- `splitWork` / `joinWork` は項目を明示的に並べているので、足した項目をここで必ず通すこと

## 保存

- `save()` は **今のコマだけ** 焼き直して新しい `versionId` にし、他のコマは前の `PageData` を
  そのまま使う（版を増やさない）。今の実装はページを 1 枚の配列で作り直しているので、
  そのままでは 2 コマ目以降が消える
- サムネイルは、今のコマが 1 コマ目のときだけ焼き直す。並べ替えで 1 コマ目が変わったら、
  新しい 1 コマ目の絵から作り直す
- コマを切り替える前に、変更があれば今のコマを保存する

## 手順（1 段ごとにアプリは動く状態を保ち、コミットする）

1. **データ**：`animation` と `activePageId` を足し、`splitWork` / `joinWork` / 読み込みで通す。テスト
2. **コマ対応の保存と読み込み**：`main.ts` の `pages[0]` 固定をやめ、今のコマを基準にする
   （`save` / `restore` / `openWork` / `trashWork` / `revertTo`）。前に戻すは全コマ。
   この段では UI からコマは増えないので、見た目も動きも今と同じ
3. **パラパラの開始**：ツールバーのボタン、かさねの統合（確認・直前の控え）、パラパラ中のかさねを休ませる
4. **コマの帯**：`LayerStrip` を引数化して再利用。選ぶ・並べ替え・＋・けす（確認）・24 の上限
5. **うすく**：前のコマを敷く canvas とスイッチ（写真の下敷き `underlayCanvas` と同じ作り・同じ場所の隣）
6. **見る**：再生
