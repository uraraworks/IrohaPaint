# いろは - Iroha Paint

> 宝箱で道具が増えていく、ブラウザで開くだけのペイント。

<img src="public/icon/leaf-192.png" width="96" alt="" />

名前の「いろは」は *ものごとのいろは*（＝入門）と *色* の掛詞。
アイコンはいろはモミジ（7 裂＝いろはにほへと）を虹の 7 色で塗ったもの。

小学校低〜中学年が **説明ゼロで 1 枚描き切れる** ことだけに全振りしたペイントソフトの
プロトタイプ（Phase 0）です。インストール不要・サーバー不要・作品はすべて端末内に保存されます。

- 公開先：https://uraraworks.github.io/IrohaPaint/
- 紹介ページ：https://uraraworks.github.io/IrohaPaint/intro.html （`public/intro.html`）
- 実装メモ・設計判断：[docs/phase0-notes.md](docs/phase0-notes.md)

## 使い方（開発）

```bash
npm install
npm run dev      # http://localhost:5200 （LAN 公開。実機の iPad / Chromebook から検証可）
npm test         # ロジックの単体テスト
npm run typecheck
npm run build    # dist/ に静的サイトを生成
```

`master` / `main` に push すると GitHub Actions が typecheck → test → build を通してから
GitHub Pages へ配置します（`.github/workflows/deploy.yml`）。`vite.config.ts` の
`base: "./"` により、リポジトリ名がどう変わっても（＝正式名称が決まって改名しても）
配置先パスを直す必要はありません。

## Phase 0 でできること

| | |
|---|---|
| 描く | ペン先 5 種（クレヨン / 色えんぴつ / Ｇペン / 筆 / 油絵）× 太さ 5 段階・クレヨン 12 色・消しゴム（太さ 3 段階）。選択中の色は「色」ボタン自体に出る |
| 紙 | 「マス」パネルの上段で ふつう / わら半紙 / キャンバス。テクスチャは画像を持たずその場で描く（サイズを選べるようにしても破綻しない）。**紙の質感は絵の一部なので書き出す PNG に焼き込む**が、保存データには焼き込まない（焼き込むと後から紙を変えられず、変えるたび二重に乗る） |
| 下敷き | 「マス」で なし / 方眼 / ビーズ / 写真 を選ぶ。絵とは別レイヤーなので保存にも書き出しにも入らない。紙とは独立した軸なので「わら半紙の上に方眼」ができる |
| 隠す | 下敷きが出ている間だけ現れるトグルで、方眼・ビーズ・写真を一時的に消す。なぞった線や完成形を確かめるためのもので、**ビーズは隠している間もマス目への吸着が続く**（抜けるのは「なし」、覗くのは「かくす」） |
| 色を吸う | 「スポイト」、または PC は右クリック（右クリックは道具を切り替えない） |
| 直す | 戻る（ボタン／2 本指タップ／Ctrl+Z）・進む（ボタン／Shift+Ctrl+Z） |
| 増える | 宝箱で道具が増える仕組み（現在は OFF。道具を整理するまで最初から全部見せている） |
| 出す | 「完成！」で PNG ダウンロード＋紙吹雪 |
| ビーズ | 下敷きに「ビーズ」を選ぶとマス目にしか置けないドット絵モード。アイロンビーズの図案を描いて見ながら作れる |
| みんなで | 「みんな」で複数人が同時に描けるモード（その間はピンチと戻るを止める） |
| ためる | 「作品」で一覧（写真が主役のカード）。あたらしく描く／過去の絵を開いて描き足す |
| 消えない | 絵は IndexedDB、増えた道具は localStorage へ自動保存。「捨てる」はゴミ箱行きで、いつでも「取り戻す」 |
| 戻せる | 作品ごとの履歴を横スクロールのタイムラインで表示し「これに戻す」。共用端末での上書き事故を復旧できる |
| 広く使う | 全画面ボタン（使える環境にだけ表示。iPhone はホーム画面に追加すると全画面で開く） |
| 見る | ピンチで拡大・2 本指ドラッグで移動。PC はホイールで移動 / Ctrl（⌘）+ ホイールで拡大。拡大中は「全部」で等倍に戻せる |
| なぞる | 「マス → 写真」で手元の画像を取り込み、下敷きにする。EXIF の向きを反映し長辺 3072px へ縮小。端末に置くのは 12 枚までで、超えたら最後に使ったのが古いものから黙って押し出す（取り込み直せるので消す操作を画面に置かない） |
| 置く | 取り込んだ直後と「動かす」で配置モードに入る。1 本指で移動・ピンチと ⌘+ホイールで拡大縮小。**この間は紙を 0.7 倍に引き、紙からはみ出す部分を薄く描く**（写真アプリの切り抜きと同じ見え方にして、動かせることを説明せずに伝える）。濃さは 3 段階 |
| 目を守る | 画面フィルタ 4 段階（ふつう / やわらか / くらい / よる）。表示だけを覆う層なので絵には影響しない。「よる」は乗算で青を減らす。反射型の電子ペーパーにはできないが、画面から出る光の量は減らせる |

## 設計の芯

- **タッチが母語、マウスが後追い**。ホバーや右クリックに機能を置かない。ヒット領域は指基準（88px 角）
- **失敗が存在しない**。パネルはいつでも開閉でき、破壊的な操作を作らない。作品も本当には消えない
- **説明しない**。起動直後にガイドを出さず、道具が増えた瞬間だけ 7 文字の吹き出しを 1 個出す
- **アイコンは自前 SVG で規格を揃える**（32×32・線 #3d3730・角丸・彩度を落としたクレヨン色）。
  絵文字は環境ごとに絵柄が変わり、消しゴムに至っては該当する絵文字が存在しない
- **データは最初から追記型**。作品 = ID 付きリスト、作品は `pages[]` を持ち、削除はフラグ、履歴は追記のみ
  （共用タブレットでの上描き事故・消し事故を後から復旧できる形にしておく）。
  作品は描かれた寸法（`canvasWidth`/`canvasHeight`）と紙の種類も記録する。後から足しても遡れないため
- **取り込んだ絵は編集できない — フラグではなく構造で**。下敷きの画像は作品ストアとは別 DB（`iroha-underlay`）に
  置く。作品ストアに入る経路が存在しないこと自体が「編集できない」の実体。下敷きは取り込み直せるので、
  作品と違いソフトデリートせず本当に消す（読めなくなったレコードも掃除する。作品では絶対にやらない）
- **見た目は「表示される大きさ」で決める**。紙のテクスチャを原寸（1748px）で作り原寸で確かめると、
  実際の表示倍率 0.51 で干渉して大きな市松模様になる。縮小してから標準偏差とブロック平均のばらつきで判定する
